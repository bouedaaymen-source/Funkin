## 🌐 Deploying to GitHub Pages

This repository includes the static GitHub Pages website in **both** `/index.html` (root) and `/docs/index.html`:
1. Push this repository to GitHub.
2. Open **Settings → Pages** on your GitHub repository.
3. Under **Build and deployment**, select **Deploy from a branch**, choose `main`, and select either `/ (root)` or `/docs`.
4. Click **Save** — your live **The Town — The 2090 Club** GitHub Page will publish automatically!
